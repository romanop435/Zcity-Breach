# 🔧 Отличия от исходного проекта

ZCity Breach не является копией оригинального Utopia Breach. В текущую сборку были внесены изменения и дополнения.

### 🏗️ Архитектура

- переработаны отдельные части игрового режима;
- добавлены новые серверные и клиентские системы;
- расширена система загрузки игровых компонентов;
- добавлены дополнительные framework-компоненты;
- добавлены собственные оптимизации;
- изменена структура некоторых игровых систем.
